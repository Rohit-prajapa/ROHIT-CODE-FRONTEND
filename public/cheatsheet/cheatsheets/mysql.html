  1. What is MySQL?

    MySQL is a Relational Database Management System (RDBMS).

It stores data in tables.

Database
   ↓
Tables
   ↓
Rows
   ↓
Columns

Example:

students

id | name  | age | course
--------------------------
1  | Rohit | 21  | CSE
2  | Aman  | 22  | IT

  66. JOIN Summary

    INNER JOIN

Only matching rows


LEFT JOIN

+ matching rows from right

+ matching rows from left

    START TRANSACTION;

SET balance = balance - 1000
WHERE id = 1;

SET balance = balance + 1000
WHERE id = 2;

COMMIT;

  87. ROLLBACK

    START TRANSACTION;

WHERE id = 10;

  88. SAVEPOINT

    START TRANSACTION;

UPDATE accounts
SET balance = balance - 500
WHERE id = 1;

SAVEPOINT payment_step;

UPDATE accounts
SET balance = balance + 500
WHERE id = 2;

ROLLBACK TO payment_step;

COMMIT;

  89. ACID Properties

    A = Atomicity

Transaction completes fully
or not at all.


C = Consistency

Database remains valid.


I = Isolation

Transactions do not incorrectly
interfere with each other.


D = Durability

Committed data remains stored.

  109. Normalization

    Normalization reduces:

Data duplication
Data inconsistency
Update anomalies


Common Normal Forms:

1NF
2NF
3NF
BCNF

  110. 1NF

    First Normal Form

Each column contains
atomic values.

Wrong:

id | phones
1  | 9876, 8765


Better:

id | phone
1  | 9876
1  | 8765

  111. 2NF

    Second Normal Form

Must be in 1NF.

No partial dependency on
part of a composite key.

  112. 3NF

    Third Normal Form

Must be in 2NF.

No transitive dependency.

Non-key columns should depend
on the key, the whole key,
and nothing but the key.
