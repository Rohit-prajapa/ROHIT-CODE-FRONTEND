    Context Switching occurs

  21. Context Switch Overhead

    Context switching consumes
CPU time.

useful application work
may not be performed.

Too many context switches
can reduce performance.

  28. Turnaround Time

    Turnaround Time

  29. Waiting Time

    Waiting Time

  30. Response Time

     - Arrival Time

  36. SJF Scheduling

    SJF =

Shortest Job First

The ready process with
the smallest predicted
CPU burst is selected.

Usually discussed as:

Non-Preemptive SJF

  37. SJF Example

    Process    Burst

P1         6

P2         2

P3         4


If all arrive together:

  38. SJF Advantage

    SJF minimizes average
waiting time for a given
set of jobs when their
CPU burst lengths are known.

Practical challenge:

Future burst time must
usually be estimated.

  39. SRTF

    SRTF =

Shortest Remaining Time First

Preemptive version of SJF.

CPU is assigned to the

  67. Deadlock

    Deadlock occurs when
a set of processes are
permanently waiting for
resources/events that can
only be caused by another
process in the same set.

Example:

P1 holds R1
and waits for R2

P2 holds R2

  68. Four Necessary Deadlock Conditions

    1. Mutual Exclusion

2. Hold and Wait

3. No Preemption

4. Circular Wait

  69. Mutual Exclusion Condition

    At least one resource
must be non-shareable.

Only one process can
use that resource
at a time.

  70. Hold and Wait

    A process holds one
or more resources

while waiting to acquire
additional resources.

  71. No Preemption

    Resources cannot simply
be forcibly taken away
under the resource model.

They are released
voluntarily by the
holding process.

  72. Circular Wait

    P1 waits for P2

P2 waits for P3

P3 waits for P1


Forms a cycle.

  85. Contiguous Memory Allocation

  86. Internal Fragmentation

    Allocated block is larger
than the requested memory.

Unused space remains
inside the allocated block.

This wasted space is:

Internal Fragmentation

  87. External Fragmentation

    Free memory exists,
but it is split into
separate non-contiguous
holes.

A large contiguous request
may fail even if total
free memory is sufficient.

  88. Memory Allocation Strategies

    First Fit

Best Fit

  89. First Fit

    Allocate the first
available memory block
large enough to satisfy
the request.

  90. Best Fit

    Allocate the smallest
available block that
is large enough for
the request.

  91. Worst Fit

    Allocate from the largest
available free block.

  108. Optimal Page Replacement

    Replace the page whose
next use is farthest
in the future.

Produces the minimum

Not directly implementable

  123. SSTF

    SSTF =

Shortest Seek Time First

Service the request
closest to the current

Can cause starvation

  124. SCAN Algorithm

    Also called:

Elevator Algorithm

Disk head moves in
one direction servicing
requests.

At the end, direction
is reversed.

  125. C-SCAN

    C-SCAN =

Circular SCAN

Head services requests
in one direction.

After reaching the end,
it returns to the beginning
and continues in the
same service direction.

  126. LOOK

    Similar to SCAN.

But the head reverses
at the last pending
request in that direction
instead of necessarily
going to the physical end.

  127. C-LOOK

    Similar to C-SCAN.

But it moves only as
far as the last request
before jumping to the
other end of the
pending request range.
