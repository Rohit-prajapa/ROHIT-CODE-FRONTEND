Git & GitHub Cheat Sheet

Complete Git and GitHub quick reference covering repositories, commits, branches, merging, remotes, push, pull, reset, revert, stash and GitHub workflow.

  1. Check Git Version

    git --version

  2. Configure Username

    git config --global user.name "Rohit Prajapati"

  3. Configure Email

    git config --global user.email "your-email@example.com"

  4. Check Git Configuration

    git config --list

  5. Initialize Git Repository

    git init

  6. Check Repository Status

    git status

  7. Add One File

    git add index.html

  8. Add Multiple Files

    git add index.html style.css script.js

  9. Add All Files

    git add .

  10. Create Commit

    git commit -m "Initial commit"

  11. Git Basic Workflow

    git status

git add .

git commit -m "Add new feature"

  12. View Commit History

    git log

  13. Short Commit History

    git log --oneline

  14. Graph Commit History

    git log --oneline --graph --all

  15. Show Changes

    git diff

  16. Show Staged Changes

    git diff --staged

  17. Show Commit Details

    git show

  18. Show Specific Commit

    git show COMMIT_ID

  19. List Branches

    git branch

  20. Create New Branch

    git branch feature-login

  21. Switch Branch

    git switch feature-login

  22. Create and Switch Branch

    git switch -c feature-login

  23. Older Checkout Syntax

    git checkout feature-login

git checkout -b feature-login

  24. Rename Branch

    git branch -m new-branch-name

  25. Delete Local Branch

    git branch -d feature-login

  26. Force Delete Local Branch

    git branch -D feature-login

  27. Merge Branch

    git switch main

git merge feature-login

  28. Abort Merge

    git merge --abort

  29. Merge Conflict Example

    <<<<<<< HEAD

Current branch code

=======

Incoming branch code

>>>>>>> feature-login

  30. After Resolving Merge Conflict

    git add .

git commit -m "Resolve merge conflict"

  31. Clone Repository

    git clone REPOSITORY_URL

  32. Clone into Custom Folder

    git clone REPOSITORY_URL my-project

  33. Check Remote Repository

    git remote -v

  34. Add GitHub Remote

    git remote add origin REPOSITORY_URL

  35. Rename Branch to main

    git branch -M main

  36. First Push to GitHub

    git push -u origin main

  37. Push Changes

    git push

  38. Push Specific Branch

    git push origin feature-login

  39. Pull Changes

    git pull

  40. Pull from Main Branch

    git pull origin main

  41. Fetch Changes

    git fetch

  42. Fetch vs Pull

    git fetch

Downloads remote changes
without automatically
merging them.


git pull

Downloads remote changes
and integrates them into
the current branch.

  43. Change Remote URL

    git remote set-url origin REPOSITORY_URL

  44. Remove Remote

    git remote remove origin

  45. Delete Remote Branch

    git push origin --delete feature-login

  46. Create .gitignore

    node_modules/

.env

dist/

build/

*.log

.vscode/

.DS_Store

  47. Remove Tracked File from Git

    git rm --cached .env

  48. Remove Tracked Folder

    git rm -r --cached node_modules

  49. Unstage File

    git restore --staged index.html

  50. Discard File Changes

    git restore index.html

  51. Amend Last Commit

    git commit --amend -m "New commit message"

  52. Reset Soft

    git reset --soft HEAD~1

    Removes the last commit but keeps changes staged.

  53. Reset Mixed

    git reset HEAD~1

    Removes the last commit and keeps changes unstaged.

  54. Reset Hard

    git reset --hard HEAD~1

    Warning: This discards local changes.

  55. Revert Commit

    git revert COMMIT_ID

  56. Reset vs Revert

    RESET

Moves branch history.

Commonly used for local
history cleanup.


REVERT

Creates a new commit that
undoes an older commit.

Usually safer for shared
repository history.

  57. Git Stash

    git stash

  58. Stash with Message

    git stash push -m "Login work"

  59. List Stashes

    git stash list

  60. Apply Latest Stash

    git stash apply

  61. Pop Latest Stash

    git stash pop

  62. Delete Stash

    git stash drop stash@{0}

  63. Delete All Stashes

    git stash clear

  64. Git Tags

    git tag v1.0.0

  65. List Tags

    git tag

  66. Annotated Tag

    git tag -a v1.0.0 -m "Version 1.0.0"

  67. Push Tag

    git push origin v1.0.0

  68. Push All Tags

    git push origin --tags

  69. Delete Local Tag

    git tag -d v1.0.0

  70. Git Rebase

    git switch feature-login

git rebase main

  71. Continue Rebase

    git add .

git rebase --continue

  72. Abort Rebase

    git rebase --abort

  73. Cherry Pick

    git cherry-pick COMMIT_ID

  74. Git HEAD

    HEAD

Points to the currently
checked-out commit.

HEAD~1

Previous commit.

HEAD~2

Two commits before HEAD.

  75. View Remote Branches

    git branch -r

  76. View All Branches

    git branch -a

  77. Clean Untracked Files

    git clean -n

git clean -f

    Run git clean -n first to preview files.

  87. Git vs GitHub

    Git
--------------------

Version control system.

Runs locally.

Tracks code changes.

Creates commits.

Handles branches.


GitHub
--------------------

Cloud platform for
hosting Git repositories.

Stores remote repositories.

Supports collaboration.

Pull Requests.

Issues.

Actions.

Project management.

  88. Common Git Error — Remote Already Exists

    error:
remote origin already exists
    git remote -v

git remote set-url origin REPOSITORY_URL

  89. Common Git Error — Rejected Push

    ! [rejected]
main -> main
(non-fast-forward)
    git pull --rebase origin main

git push origin main

  90. Common Git Error — Unrelated Histories

    git pull origin main --allow-unrelated-histories

  91. Common Git Error — Nothing to Commit

    nothing to commit,
working tree clean

    This means Git currently has no new tracked changes to commit.
