  1. What is HTTP?

    HTTP =
Hypertext Transfer Protocol

HTTP is an application-layer protocol
used for communication between:

Client
   ↓
Server


Example:

Browser
   ↓
HTTP Request
   ↓
Server
   ↓
HTTP Response
   ↓
Browser

Integrity

OPTIONS

not idempotent.

  22. Important 4xx Status Codes

    400 Bad Request

Invalid request


401 Unauthorized

or invalid

Authenticated or identified,

Resource not found

HTTP method not supported

  23. Important 5xx Status Codes

    CORS =
Cross-Origin Resource Sharing

CORS is a browser mechanism
that allows servers to specify
which cross-origin requests
are permitted.

  53. Origin

    Origin consists of:

Scheme

Host

Port


Example:

http://localhost:3000

and

http://localhost:5000

are different origins
because the ports differ.

  57. Fetch API — GET

    fetch("https://api.example.com/users")
    .then(response => {
        if (!response.ok) {
            throw new Error("Request failed");
        }

        return response.json();
    })
    .then(data => {
        console.log(data);
    })
    .catch(error => {
        console.error(error);
    });

  58. Fetch API with async/await

    async function getUsers() {

    try {

        const response =
            await fetch("https://api.example.com/users");

        if (!response.ok) {
            throw new Error("Request failed");
        }

        const data = await response.json();

        console.log(data);

    } catch (error) {

        console.error(error);

    }
}

getUsers();

  59. Fetch API — POST

    async function createUser() {

    const response =
        await fetch("https://api.example.com/users", {

            method: "POST",

            headers: {
                "Content-Type": "application/json"
            },

            body: JSON.stringify({
                name: "Rohit",
                course: "B.Tech"
            })
        });

    if (!response.ok) {
        throw new Error("Failed to create user");
    }

    const data = await response.json();

    console.log(data);
}

createUser();
