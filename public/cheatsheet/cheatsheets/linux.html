Linux Commands Cheat Sheet

Complete Linux command-line quick reference covering navigation, files, directories, permissions, processes, networking, SSH, packages and system administration.

  1. What is Linux?

    Linux is an open-source operating system.

Popular Linux Distributions:

Ubuntu
Debian
Fedora
Arch Linux
Linux Mint
Kali Linux
Red Hat
CentOS Stream

Linux is widely used for:

Servers
Cloud Computing
DevOps
Cybersecurity
Programming
Containers
Supercomputers

  2. Linux Command Structure

    command [options] [arguments]
    ls -la /home
    ls       = command

-la      = options

/home    = argument

  3. Print Current Directory — pwd

    pwd
    Example Output:

/home/rohit/projects

  4. List Files — ls

    ls
    ls -l
    ls -a
    ls -la

  5. Useful ls Options

    ls

List files


ls -l

Long format


ls -a

Show hidden files


ls -h

Human-readable sizes


ls -lh

Detailed + readable sizes


ls -la

Detailed + hidden files

  6. Change Directory — cd

    cd Documents
    cd /home/rohit

  7. Important cd Commands

    # Home directory
cd ~

# Parent directory
cd ..

# Previous directory
cd -

# Root directory
cd /

# Current directory
cd .

  8. Absolute vs Relative Path

    Absolute Path:

/home/rohit/projects/app


Relative Path:

projects/app


Absolute path starts
from root /

Relative path starts
from current directory.

  9. Create Directory — mkdir

    mkdir project
    mkdir html css javascript

  10. Create Nested Directories

    mkdir -p project/src/components

  11. Remove Empty Directory

    rmdir folder

  12. Create Empty File — touch

    touch index.html
    touch style.css script.js

  13. Display File Content — cat

    cat file.txt

  14. Create File Using cat

    cat > notes.txt
    Type your content.

Press:

Ctrl + D

to save and exit.

  15. Append Using cat

    cat >> notes.txt

  16. View File with less

    less largefile.txt
    Useful for large files.

Press:

q

to exit.

  17. View File with more

    more file.txt

  18. First Lines — head

    head file.txt
    head -n 20 file.txt

  19. Last Lines — tail

    tail file.txt
    tail -n 20 file.txt

  20. Watch Log File Live

    tail -f app.log
    Useful for:

Server logs
Application logs
Debugging

  21. Copy File — cp

    cp file.txt backup.txt

  22. Copy File to Directory

    cp file.txt Documents/

  23. Copy Directory

    cp -r project backup/

  24. Move File — mv

    mv file.txt Documents/

  25. Rename File

    mv old.txt new.txt

  26. Delete File — rm

    rm file.txt

  27. Delete Directory

    rm -r folder

  28. Force Delete

    rm -rf folder
    WARNING:

rm -rf permanently removes files.

Use it carefully.

There is usually no Recycle Bin
for command-line deletion.

  29. Wildcard — *

    ls *.txt
    rm *.log
    * matches zero or more characters.

  30. Wildcard — ?

    ls file?.txt
    ? matches exactly one character.

  31. Find Files — find

    find . -name "index.html"

  32. Find by Extension

    find . -name "*.js"

  33. Find Directories

    find . -type d -name "node_modules"

  34. Find Files Only

    find . -type f

  35. Search Text — grep

    grep "hello" file.txt

  36. Case-Insensitive Search

    grep -i "hello" file.txt

  37. Recursive Search

    grep -r "TODO" .

  38. Show Line Numbers with grep

    grep -n "error" app.log

  39. Count Lines — wc

    wc -l file.txt

  40. wc Options

    # Lines
wc -l file.txt

# Words
wc -w file.txt

# Bytes
wc -c file.txt

  41. Sort File Content

    sort names.txt
    sort -r names.txt

  42. Remove Adjacent Duplicate Lines — uniq

    sort names.txt | uniq

  43. Pipe Operator — |

    ls -la | grep ".js"
    Pipe sends output of one command
as input to another command.

Command 1
   |
   v
Command 2

  44. Output Redirection — >

    echo "Hello Linux" > file.txt
    > overwrites the file.

  45. Append Redirection — >>

    echo "New line" >> file.txt
    >> appends content.

  46. Input Redirection — <

    sort < names.txt

  47. Standard Streams

    0 = stdin

1 = stdout

2 = stderr

  48. Redirect Errors

    command 2> errors.txt

  49. Redirect Output and Errors

    command > output.txt 2>&1

  50. echo Command

    echo "Hello World"
    echo $HOME

    history

    clear

Ctrl + L

    sudo command

elevated privileges when
the user is authorized.

  60. File Permissions

    r = Read

w = Write

x = Execute


Example:

-rwxr-xr--


Owner:
rwx

Group:
r-x

Others:
r--

  61. View Permissions

    ls -l

  62. chmod

    chmod +x script.sh
    Add execute permission.

  63. Numeric Permissions

    Read    = 4

Write   = 2

Execute = 1


7 = rwx

6 = rw-

5 = r-x

4 = r--

  64. chmod 755

    chmod 755 script.sh
    Owner:

7 = rwx


Group:

5 = r-x


Others:

5 = r-x

  65. chmod 644

    chmod 644 file.txt
    Owner:

rw-


Group:

r--


Others:

r--

  66. Change Owner — chown

    sudo chown rohit file.txt

  67. Change Owner and Group

    sudo chown rohit:developers file.txt

the process.

  126. Command Chaining — &&

    mkdir project && cd project
    Second command runs only if
first command succeeds.

  127. OR Operator — ||

    cd project || echo "Folder not found"
    Second command runs if
first command fails.

  141. Cron Format

    * * * * * command

│ │ │ │ │
│ │ │ │ └── Day of Week
│ │ │ └──── Month
│ │ └────── Day of Month
│ └──────── Hour
└────────── Minute

  142. Cron Example

    0 9 * * * /home/user/backup.sh
    Runs every day at 9:00 AM.

  146. Important Linux Directories

    /       Root

/home   User home directories

/root   Root user's home

/etc    Configuration files

/bin    Essential commands

/usr    User applications/data

/var    Variable data/logs

/tmp    Temporary files

/dev    Device files

/proc   Process/kernel information

/boot   Boot files

/opt    Optional software

/mnt    Mount points
