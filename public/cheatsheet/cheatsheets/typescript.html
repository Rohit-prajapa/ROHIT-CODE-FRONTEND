TypeScript Cheat Sheet

Complete TypeScript quick reference covering types, functions, objects, interfaces, classes, generics, modules, DOM and modern TypeScript development.

  1. What is TypeScript?

    TypeScript is JavaScript with static typing.

TypeScript
    ↓
Compiler
    ↓
JavaScript
    ↓
Browser / Node.js

Main Benefits:

Type Safety
Better Autocomplete
Early Error Detection
Better Code Maintenance
Interfaces
Generics
Advanced Types

  2. Install TypeScript

    npm install -g typescript

  3. Check TypeScript Version

    tsc --version

    tsc app.ts

    let name = "Rohit";

let age = 21;

age    → number

  12. Any Type

    let value: any;

value = "Hello";

value = 100;

value = true;

    Use any carefully because it disables most type checking.

  13. Unknown Type

  50. Abstract Class

    abstract class Shape {

    abstract area(): number;

}


class Circle extends Shape {

    constructor(
        public radius: number
    ) {

        super();

    }


    area(): number {

        return Math.PI *
            this.radius *
            this.radius;

    }

}

  69. Fetch API with TypeScript

    interface User {

    id: number;

    name: string;

    email: string;

}


async function getUsers():
    Promise<User[]> {

    const response =
        await fetch(
            "/api/users"
        );


    const users: User[] =
        await response.json();


    return users;

}
