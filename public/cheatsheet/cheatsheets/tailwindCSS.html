Tailwind CSS Cheat Sheet

Complete Tailwind CSS quick reference covering layout, spacing, typography, colors, flexbox, grid, responsive design, hover effects and components.

  1. Install Tailwind CSS

    npm install tailwindcss @tailwindcss/cli

  2. Import Tailwind CSS

    @import "tailwindcss";

  3. Tailwind CLI

    npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch

  4. Include Generated CSS

    <link
    rel="stylesheet"
    href="./src/output.css"
>
